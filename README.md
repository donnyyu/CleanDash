# CleanDash

A clean, bloat-free Android launcher for aftermarket car head units (the FYT / TS10 / Joying-style units sold on AliExpress).

Inspired by [cleanyourtv](https://github.com/Gathin23/cleanyourtv).

## Goals

- Big, glanceable tiles that are easy to tap while driving
- Fast startup, low memory use on budget hardware
- Quick access to navigation, music, and phone
- No ads, no tracking, no bloat

## Status

Early planning — nothing to install yet.
